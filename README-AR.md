# امتحاني AI — ربط أولي فعلي بنماذج مجانية

## ما الجاهز؟
- صفحة HTML تستدعي `/api/tutor` عند إرسال سؤال.
- خادم Node.js يستخدم OpenRouter ويرسل الطلب إلى قائمة نماذج احتياطية بالترتيب.
- القائمة الافتراضية تستخدم معرّفات نماذج مجانية تنتهي بـ `:free` فقط.
- إذا انتهت الحصة أو فشلت النماذج، يتوقف الطلب برسالة واضحة ولا يُجرّب نموذجًا مدفوعًا.
- حدّ تجريبي إجمالي 30 طلبًا لكل 24 ساعة، وحد قصير 10 طلبات في الدقيقة.
- نقطة فحص: `/api/health` تُظهر هل إعدادات الخادم موجودة دون كشف المفتاح.

## ما الذي لا يزال مطلوبًا؟
لا يمكن تشغيل ردود حقيقية من هذه الحزمة وحدها؛ يلزم إنشاء حساب OpenRouter بنفسك، نسخ مفتاح API، ثم ضبطه كمتغير بيئة على الخادم. لا ترسل المفتاح في المحادثة ولا تضعه داخل HTML. صفحة OpenRouter الرسمية تذكر إمكانية البدء بالخطة المجانية دون بطاقة، وتعرض حاليًا حد 50 طلبًا يوميًا للنماذج المجانية؛ قد تتغير الحدود، وبعض الطلبات الفاشلة تُحسب ضمنها. راجع: https://openrouter.ai/pricing و https://openrouter.ai/docs/api-reference/limits

## التشغيل المحلي
1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع وانسخ `.env.example` إلى `.env`، وضع مفتاحك في `OPENROUTER_API_KEY` محليًا فقط.
3. ثبّت الاعتماديات: `npm install`
4. شغّل الخادم: `npm start`؛ سيقرأ ملف `.env` تلقائيًا عبر `dotenv`.
5. افتح الموقع عبر نفس الخادم أو اضبط reverse proxy ليصل `/api/tutor` إلى Node.js. فتح ملف HTML مباشرة من `file://` لن يكفي.

## حدود الأمان الحالية
- الخادم يرفض أي إعداد نموذج لا ينتهي بـ `:free`؛ هذه حماية إضافية وليست ضمانًا أن المزوّد سيبقي النموذج مجانيًا إلى الأبد. راجع السعر قبل تغيير المعرّفات.
- لا تفعّل فوترة مدفوعة إن كان المطلوب صفر تكلفة، وتحقق من إعدادات الحساب دوريًا.
- حد 30 طلبًا حاليًا عام للمنصة وليس 3 لكل طالب؛ لا يوجد تسجيل دخول أو قاعدة بيانات مستخدمين بعد.
- عدّاد الحد اليومي يستخدم الذاكرة ويُعاد عند إعادة تشغيل الخادم. قبل نشره لطلاب فعليين، استبدله بتخزين دائم وأضف مصادقة وحدًا يوميًا لكل حساب.
- النماذج المجانية قد تحتفظ بالطلبات وفق شروط المزوّد؛ لا ترسل معلومات شخصية أو حساسة أو بيانات طلاب خاصة.
